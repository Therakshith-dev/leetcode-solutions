LeetCode 24 — Swap Nodes in Pairs

Core Idea

We do not swap values. We rewire pointers.

For every pair:

  • First node skips second
  • Second points to first
  • Previous connects to second

Repeat until fewer than two nodes remain.

Critical Pointer Rewiring

first_node.next = second_node.next
second_node.next = first_node
previous_node.next = second_node

These three lines perform the swap.

If you change the order, the structure breaks.

Why We Need a Fixed Starting Node

fixed_list = ListNode(0)
fixed_list.next = input_list

If the first pair swaps, the head changes. The fixed node ensures we never lose the new head.

Full Implementation

from typing import Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def swapPairs(self, input_list: Optional[ListNode]) -> Optional[ListNode]:

        if not input_list or not input_list.next:
            return input_list

        fixed_list = ListNode(0)
        fixed_list.next = input_list

        previous_node = fixed_list

        while previous_node.next and previous_node.next.next:

            first_node = previous_node.next
            second_node = previous_node.next.next

            first_node.next = second_node.next
            second_node.next = first_node
            previous_node.next = second_node

            previous_node = first_node

        return fixed_list.next
