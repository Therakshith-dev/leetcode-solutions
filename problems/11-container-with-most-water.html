LeetCode 11 — Container With Most Water

Detailed Explanation (Two Pointers)

We are given an array height. Each value is a vertical line at that index. If we pick two lines at indices left and right, they form a container.

The amount of water that container can hold is: 

area = width × height

Width is the distance between the two indices: 

width = right - left

Height is limited by the shorter wall, because water will spill over the shorter side: 

height = min(height[left], height[right])

Why Two Pointers Works

We start with the widest possible container: left = 0 and right = n - 1. That gives the maximum width.

Then we compute the area and try to improve it by moving pointers inward. But the key question is: Which pointer should we move?

Key Insight: Move the Shorter Wall

Suppose height[left] < height[right]. That means the left wall is the limiting wall. The water level cannot go above height[left] no matter how tall the right wall is.

If we move the right pointer inward while keeping the shorter left wall, two bad things happen:

  • The width becomes smaller (right - left decreases).
  • The height is still limited by the same short left wall.

So the area cannot increase by moving the taller side while the shorter side stays the same. The only chance to get a larger area is to find a taller left wall.

That’s why when height[left] < height[right], we do: 

left += 1

And if height[right] <= height[left], then the right wall is limiting, so we try to find a taller right wall by doing: 

right -= 1

What the Loop Guarantees

Every step reduces the width, so we must compensate by trying to increase the minimum height. Moving the shorter pointer is the only move that can potentially increase the minimum height.

We keep track of the best answer in max_area, and when the pointers cross, we’ve tested all useful candidates and return the maximum.

Code

def maxArea(height):
    left = 0
    right = len(height) - 1
    max_area = 0

    while left < right:
        width = right - left
        h = min(height[left], height[right])
        area = width * h
        max_area = max(max_area, area)

        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_area
