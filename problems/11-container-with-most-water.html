LeetCode 11 — Container With Most Water

Approach

  • Left pointer at 0
  • Right pointer at n − 1
  • Width = right − left
  • Height = min(height[left], height[right])
  • Area = width × height
  • Update max_area
  • Move the smaller pointer inward

Code

def maxArea(height):
    left = 0
    right = len(height) - 1
    max_area = 0

    while left < right:
        width = right - left
        h = min(height[left], height[right])
        area = width * h
        max_area = max(max_area, area)

        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_area
