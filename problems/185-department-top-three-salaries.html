LeetCode 185 — Department Top Three Salaries

Core Idea

We must find employees whose salary is in the top three unique salaries within their department.

The key word is unique. If two employees earn the same salary, they share the same rank.

The cleanest way to solve this in PostgreSQL is by using:

  • DENSE_RANK()
  • PARTITION BY
  • ORDER BY salary DESC

Critical Ranking Logic

DENSE_RANK() OVER (
    PARTITION BY departmentId
    ORDER BY salary DESC
)

This assigns a rank inside each department separately.

  • Highest salary → Rank 1
  • Second highest unique salary → Rank 2
  • Third highest unique salary → Rank 3

Employees with the same salary receive the same rank.

Why We Use DENSE_RANK (Not ROW_NUMBER)

ROW_NUMBER() → gives every row a unique number
RANK() → leaves gaps when ties exist
DENSE_RANK() → no gaps, handles duplicates correctly

Example (IT Department):

  • 90000 → Rank 1
  • 85000 → Rank 2
  • 85000 → Rank 2
  • 70000 → Rank 3
  • 69000 → Rank 4

We only keep ranks ≤ 3.

Complete PostgreSQL Query

SELECT
    d.name AS "Department",
    e.name AS "Employee",
    e.salary AS "Salary"
FROM (
    SELECT
        *,
        DENSE_RANK() OVER (
            PARTITION BY departmentId
            ORDER BY salary DESC
        ) AS rnk
    FROM Employee
) e
JOIN Department d
    ON e.departmentId = d.id
WHERE e.rnk <= 3;

How It Works Step-by-Step

  1. Rank employees inside each department using DENSE_RANK.
  2. Keep only employees where rank ≤ 3.
  3. Join Department table to get department names.

Time complexity is efficient because window functions are optimized in PostgreSQL.
