LeetCode 74 — Search a 2D Matrix

Core Idea

The matrix is globally sorted. We can treat it like a virtual 1D sorted array and apply binary search.

Critical Logic

elif value < target:
    left = middle + 1

If the current value is smaller than the target, then everything to the left of it is also smaller (because the matrix is sorted).

So we discard the entire left half and search only the right half.

Full Implementation

from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:

        if not matrix or not matrix[0]:
            return False

        rows = len(matrix)
        cols = len(matrix[0])

        left = 0
        right = rows * cols - 1

        while left <= right:
            middle = (left + right) // 2

            row = middle // cols
            col = middle % cols

            value = matrix[row][col]

            if value == target:
                return True
            elif value < target:
                left = middle + 1
            else:
                right = middle - 1

        return False
