LeetCode 74 — Search a 2D Matrix

Core Idea

The matrix is globally sorted. We treat it as a virtual 1D sorted array and perform binary search.

Critical Binary Search Logic

elif value < target:
    left = middle + 1

If the current value is smaller than the target, then everything to the left is also smaller (because the matrix is sorted).

So we discard the entire left half and search only in the right half.

Why // and % Work

row = middle // cols
col = middle % cols

We are pretending the matrix is flattened into one long array.

If each row has cols elements:

  • middle // cols tells us how many full rows we skip → that gives the row index.
  • middle % cols tells us how far inside that row we are → that gives the column index.

Example: if cols = 4 and middle = 6

  • 6 // 4 = 1 → row 1
  • 6 % 4 = 2 → column 2

So index 6 in the virtual array maps to matrix[1][2].

Full Implementation

from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:

        if not matrix or not matrix[0]:
            return False

        rows = len(matrix)
        cols = len(matrix[0])

        left = 0
        right = rows * cols - 1

        while left <= right:
            middle = (left + right) // 2

            row = middle // cols
            col = middle % cols

            value = matrix[row][col]

            if value == target:
                return True
            elif value < target:
                left = middle + 1
            else:
                right = middle - 1

        return False
