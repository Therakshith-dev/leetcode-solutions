LeetCode 2468 — Split Message Based on Limit

Core Idea

We try different values of b (number of parts). For each candidate b, we compute the total capacity available to store message characters.

Suffix format: <a/b>

Suffix length = digits(a) + digits(b) + 3

Critical Capacity Condition

if suffix_length >= limit:
    break

If the suffix itself takes up the entire limit, there is no space left to store message characters. That value of b is impossible.

Why Digit Grouping Works

digits = len(str(a))
end = min(b, 10**digits - 1)
count = end - a + 1

Instead of iterating through every a individually, we group indices by digit length:

  • 1–9 → 1 digit
  • 10–99 → 2 digits
  • 100–999 → 3 digits

This reduces time complexity and avoids TLE.

Full Implementation

class Solution:
    def splitMessage(self, message: str, limit: int):
        n = len(message)

        for b in range(1, n + 1):
            len_b = len(str(b))
            total_capacity = 0

            a = 1
            while a <= b:
                digits = len(str(a))
                end = min(b, 10**digits - 1)
                count = end - a + 1

                suffix_length = digits + len_b + 3

                if suffix_length >= limit:
                    total_capacity = -1
                    break

                total_capacity += count * (limit - suffix_length)
                a = end + 1

            if total_capacity < n:
                continue

            result = []
            index = 0

            for a in range(1, b + 1):
                suffix = f"<{a}/{b}>"
                cap = limit - len(suffix)
                part = message[index:index + cap]
                index += cap
                result.append(part + suffix)

            return result

        return []
