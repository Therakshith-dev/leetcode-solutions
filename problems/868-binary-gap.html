LeetCode 868 — Binary Gap

Core Idea

We scan the binary representation of a number from right to left.

Instead of storing positions of 1s, we count how many zeros occur between consecutive 1s.

Distance = zeros_between + 1

We use:

  • counter → counts zeros after first 1
  • max_distance → stores the largest gap

Critical Reset Logic

if number % 2 == 1:
    counter = 0

When we encounter a 1:

  • If it's the first 1 → start counting
  • If it's not the first → compute distance
  • Reset counter because this 1 becomes the new anchor

Bit Movement Mechanism

number = number // 2

Dividing by 2 removes the least significant bit.

Example (22): 

22 → 10110
11 → 1011
5  → 101
2  → 10
1  → 1

Each loop shifts right by one bit.

Detailed Dry Run — n = 22

Binary: 10110

Right to Left Scan:

Bit:      0  1  1  0  1
Index:    0  1  2  3  4
Step-by-step: 
Initial:
counter = -1
max_distance = 0

Bit 0 → ignore (haven't seen first 1)

Bit 1:
counter = 0

Bit 1:
distance = 0 + 1 = 1
max_distance = 1
counter = 0

Bit 0:
counter = 1

Bit 1:
distance = 1 + 1 = 2
max_distance = 2
counter = 0
Final Answer: 2

Another Example — n = 9

Binary: 1001 
1 0 0 1

First 1 → counter = 0
0 → counter = 1
0 → counter = 2
Second 1 → distance = 2 + 1 = 3
Final Answer: 3

Full Implementation (Counter Method)

class Solution:
    def binaryGap(self, number: int) -> int:
        max_distance = 0
        counter = -1

        while number > 0:
            if number % 2 == 1:
                if counter != -1:
                    max_distance = max(max_distance, counter + 1)
                counter = 0
            else:
                if counter != -1:
                    counter += 1

            number = number // 2

        return max_distance

Why This Is Elegant

  • No array storage
  • No position tracking
  • Constant space
  • Single pass
  • Mathematically equivalent to index difference

Complexity

  • Time: O(log n)
  • Space: O(1)
