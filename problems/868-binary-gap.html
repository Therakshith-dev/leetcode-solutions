LeetCode 868 — Binary Gap

Core Idea

We scan the binary representation from right to left and measure the distance between consecutive 1s.

Distance = zeros_between + 1

A gap starts only when a 1 appears. Zeros extend the gap. The next 1 terminates the gap.

Why We Do Not Reset On Zero

A 0 does not start a gap. A 1 starts and ends a gap.

If we reset the counter when a 0 appears, we would lose the distance between two 1s. 

Example: 1001

Correct:
1 → counter = 0
0 → counter = 1
0 → counter = 2
1 → distance = 3

If reset on 0:
1 → counter = 0
0 → counter = 0
0 → counter = 0
1 → distance = 1 (incorrect)

Zeros increase distance. Ones compute and reset.

Why Counter Starts At -1

Counter = -1 means no 1 has been seen yet.

Leading zeros must be ignored. When the first 1 appears, tracking begins.

Dry Run — n = 22

Binary: 10110
Scan:   0 → 1 → 1 → 0 → 1

Bit 0 → ignore
Bit 1 → counter = 0
Bit 1 → distance = 1
Bit 0 → counter = 1
Bit 1 → distance = 2
Final Answer = 2

Implementation

class Solution:
    def binaryGap(self, number: int) -> int:
        max_distance = 0
        counter = -1

        while number > 0:
            if number % 2 == 1:
                if counter != -1:
                    max_distance = max(max_distance, counter + 1)
                counter = 0
            else:
                if counter != -1:
                    counter += 1

            number = number // 2

        return max_distance

Performance Statistics

  • Time Complexity: O(log n)
  • Space Complexity: O(1)

The loop runs once per bit. The number of bits in n is log₂(n). Only constant variables are used.
