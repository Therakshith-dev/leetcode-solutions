LeetCode 868 — Binary Gap

Core Idea

We scan the binary representation of a number from right to left.

Each time we encounter a 1, we calculate the distance from the previous 1.

We keep track of:

  • The last position where a 1 was found
  • The maximum distance seen so far

Critical Condition

if n % 2 == 1:

This checks whether the current least significant bit is 1.

Since binary numbers alternate between even and odd:

  • Odd number → last bit is 1
  • Even number → last bit is 0

How We Move Through Bits

n = n // 2

Integer division by 2 removes the last binary bit.

Example for n = 22:

  • 22 → 10110
  • 11 → 1011
  • 5 → 101
  • 2 → 10
  • 1 → 1

Each iteration moves one bit to the right.

Step-by-Step Example (n = 22)

Binary of 22 = 10110

  • Position 0 → 0 → ignore
  • Position 1 → 1 → last_position = 1
  • Position 2 → 1 → distance = 2 - 1 = 1
  • Position 3 → 0 → ignore
  • Position 4 → 1 → distance = 4 - 2 = 2

Maximum distance = 2

Full Implementation

class Solution:
    def binaryGap(self, n: int) -> int:
        last_position = -1
        max_distance = 0
        position = 0

        while n > 0:
            if n % 2 == 1:
                if last_position != -1:
                    max_distance = max(max_distance, position - last_position)
                last_position = position

            n = n // 2
            position += 1

        return max_distance

Time & Space Complexity

  • Time: O(log n) → one pass through binary digits
  • Space: O(1)
